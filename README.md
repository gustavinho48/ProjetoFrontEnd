🇧🇷 CulturaBrasil

Portal acadêmico sobre as tradições, a arte, a gastronomia e o turismo das cinco regiões do Brasil. Projeto desenvolvido para a disciplina DFEW.08 - Projeto Front-End para Web, da Universidade Positivo, sob orientação do Prof. Fabricio Olivo.

🔗 Site publicado: https://gustavinho48.github.io/ProjetoFrontEnd/

📌 Sobre o projeto

O CulturaBrasil apresenta, de forma visual e interativa, as manifestações culturais de cada região do país: festas populares, música, folclore, culinária e patrimônios naturais e históricos.

Região	Destaques
Norte	Festival de Parintins, Círio de Nazaré, tacacá e açaí
Nordeste	Frevo, maracatu, São João, cordel
Centro-Oeste	Pantanal, Viola de Cocho, Cavalhadas de Pirenópolis, arroz com pequi
Sudeste	Samba carioca, cidades históricas de Minas Gerais, gastronomia caipira e caiçara
Sul	Cultura gaúcha, chimarrão, festas de imigração alemã e italiana, barreado

✨ Funcionalidades
Navegação responsiva com Bootstrap (menu com dropdown de regiões)
Personalização do visitante com nome salvo no LocalStorage
Contador interativo de explorações, também persistido no navegador
Alternância entre modo claro e modo escuro
Páginas dedicadas para cada uma das 5 regiões
Diário Cultural
Galeria com CSS Grid Layout e players nativos de áudio e vídeo
Duas páginas em HTML5/CSS3 puro, sem frameworks: Estatísticas (tabela) e Sobre
Página de contato
Links externos de referência (W3C, IPHAN, Ministério do Turismo, IBGE Educa)
Funciona 100% offline, pois o Bootstrap e os ícones estão incluídos localmente

🛠️ Tecnologias
HTML5
CSS3
JavaScript 
Bootstrap 5 e Bootstrap Icons (arquivos locais)
